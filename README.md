# Liceo 8888 🎫

**Liceo 8888** is a centralized communication platform designed to bridge the gap between students and administration. It allows students to submit queries, complaints, and suggestions through a structured **ticketing system**, ensuring every concern is tracked, managed, and resolved efficiently.

---

## 🚀 Key Features

- 🎫 Ticket-based complaint and query submission  
- 🔍 Real-time ticket tracking and status updates  
- 🧑‍💼 Admin and department-based ticket management  
- 🔐 Secure authentication and role-based access  
- 📊 Organized dashboard for monitoring concerns  
- 💬 Structured communication between users and admins  

---

## 🧩 User Roles

| Role | Description |
|-----|------------|
| **User (Student)** | Submits tickets and tracks their progress |
| **Admin** | Reviews and assigns tickets to departments |
| **Department Staff** | Handles and resolves assigned tickets |
| **Super Admin** | Full system control and management |

## 🛠️ Getting Started

### Prerequisites
* Node.js (v18 or higher)
* A Supabase Project

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/liceo-8888.git](https://github.com/your-username/liceo-8888.git)
    cd liceo-8888
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Setup Environment Variables:**
    Create a `.env` file in the root directory and add your Supabase credentials:
    ```env
    PUBLIC_SUPABASE_URL=your_supabase_project_url
    PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
    ```

4.  **Run the development server:**
    ```bash
    npm run dev
    ```
